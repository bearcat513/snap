    Templates

    Pick one from Template ▾ in the editor to pre-fill the description, notes, steps and tags. Empty fields are filled; notes are appended; tags are added. A template can also set its own placeholder text and add its own fields, which show in the editor (and in exports) only while that template is active.

      Color palette

        Recording

        Chrome only lets extensions ask for the microphone from a visible page, so grant it once here.

        Keys typed into password fields are never shown. Plain typing in text boxes is shown as “typing…”, not as the characters.

        Stores each clicked element's name (button text, field label) and position, never what you type. The editor's Generate guide turns them into steps and keyframes.

        Uses Chrome's on-device speech recognition only: if it isn't available, no captions are made and no audio is sent anywhere.

        Quality

        Higher settings make larger files. About per minute at this bitrate.

        GIF export

        GIFs cover at most the first 20 seconds of the exported range.

        ServiceNow instances

        Built in: *.service-now.com, *.servicenowservices.com. Add custom domains below. Chrome will ask for access to each one.

        Chrome only lets an extension screenshot a tab without a click or shortcut if it can read every site (<all_urls>). Leave this off to keep access limited to ServiceNow; /snap will then ask you to press the shortcut.

          SN Utils script command: copy snutils/snap-command.js from the extension folder into a new SN Utils slash command named /snap. Use the latest copy: it also reads the instance's attachment size and type limits so the editor can warn before uploading.

          Issue trackers

          Configured destinations appear in the editor's Destinations panel. Tokens are kept on this device only (not synced). Chrome asks for access to each site on the first save.

          Jira

          Leave the email empty for a Server / Data Center personal access token. Creates an issue with the capture's context and attaches the files you pick.

          GitHub Issues
          Webhook

          POSTs multipart/form-data: a metadata JSON part (title, context, environment, links) and each file as file. A JSON reply with a url is shown as the saved location.

          Amazon S3

          Uploads use presigned URLs from your own service. No AWS credentials are stored in the extension.

          Library

          Oldest captures that were already saved somewhere are removed first. Unsaved captures are never removed automatically.

          About & diagnostics

          Snap Companion ·

          Recent errors are kept on this device so you can send them to whoever supports the extension. The copy includes the version, browser, your settings without tokens, and the last 100 errors, with URLs cut to their origin and path.

            Back up or share settings

            Saves your settings, templates, custom fields and palette to a file you can import on another device or give to a teammate. Tokens and your Jira email are left out, and settings managed by your organization aren't changed.
