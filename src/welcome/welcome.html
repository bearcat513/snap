Welcome to Snap Companion

Screenshots and screen recordings you can annotate, redact and send where they're needed. Captures stay on this device until you choose a destination.

1. Pin it to the toolbar

Click the puzzle-piece icon next to the address bar, then the pin beside Snap Companion. The icon is where every capture starts, and its badge shows recording and session status.

2. Learn the shortcuts

    3. Choose where captures go

    Everything can be downloaded with no setup. To send captures somewhere else, set up the destination first:

    • Jira, GitHub Issues or a webhook
    • Amazon S3
    • Default destinations and file names

    4. Using ServiceNow?

    Add the /snap command to SN Utils to attach captures to the record you're on. The script is snutils/snap-command.js in the extension folder. If your instance uses a custom domain, add it in Settings.

    5. Recording narration?

    Chrome only lets extensions ask for the microphone from a visible page, so enable it once in Settings.
